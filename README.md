# Complete Web Development Course

Practice folder for web development learning projects.

## Structure

```
Complete_web_development_course/
├── README.md
├── .gitignore
└── projects/          # add project folders here as you learn
```

## How I use this repo

- Keep course notes, exercises, and small demos here.
- Create a new subfolder for each project (e.g. `projects/todo-app`).
- Commit and push regularly so your work is backed up on GitHub.
